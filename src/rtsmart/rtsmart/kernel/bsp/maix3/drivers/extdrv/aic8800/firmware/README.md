# AIC8800 firmware

This repository provides the firmware files used by the CanMV K230 RT-Smart
AIC8800 USB/SDIO driver.

The `usb/` and `sdio/` directories contain transport-specific files. Files with
the same name are not necessarily interchangeable between transports.
