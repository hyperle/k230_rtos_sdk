## 关键发现：CLK0 的连接器标注相反

主板 U7 和 SC132GS 板 U3 的符号方向相反。按直接叠插及其余信号的位置推导，
偶数脚对应关系是 `U7(n) ↔ U3(42−n)`，奇数脚是 `U7(n) ↔ U3(40−n)`。
这是根据图片及用户确认的叠插方式作出的推断，尚无 PCB 网表或通断测量佐证。

| 主板 U7 引脚及网络名 | SC132GS 板 U3 引脚及网络名 | 对应结果 |
| --- | --- | --- |
| 37 / 35：IIC1_SCL / SDA | 3 / 5：IIC1_SCL / SDA | 一致 |
| 20 / 18：CSI_D0+ / − | 22 / 24：CSI_D0+ / − | 一致 |
| 8 / 6：CSI_D1+ / − | 34 / 36：CSI_D1+ / − | 一致 |
| 24 / 26：CSI_D2+ / − | 18 / 16：CSI_D2+ / − | 一致 |
| 38 / 36：CSI_D3+ / − | 4 / 6：CSI_D3+ / − | 一致 |
| **12：CSI_CLK0+** | **30：CSI_CLK0−** | **相反** |
| **14：CSI_CLK0−** | **28：CSI_CLK0+** | **相反** |

旧 SC038HGS 板 U2 的 28/30 脚标为 CLK0−/＋，与上述主板对应一致；
不能把这张旧图的时钟极性直接用于 SC132GS 板。
SC132GS 板自己的 U3 CLK0+ / − 到 FPC1 9 / 8 脚的网络名一致，
疑点位于板间连接处，不是模组针脚表的正反编号。

V3.0 第 15 页表 1-8 和 V2.6 第 14 页表 1-8 均记载 `0x3654[3]` 为时钟反向，
`[2:0]` 为时钟延时。此前驱动未设置该位。
本次增加 `MPP_SC132GS_CSI0_CLOCK_INVERT`，通用默认关闭，在 Dart SC132GS
defconfig 中开启；仅对 CSI0 设置 bit 3，保留延时及其他位，并读回校验。
若写入失败或读回不符，初始化失败并保持停流。全幅、VGA 均执行此设置。

这是按给定图纸实现的时钟反向补偿候选，**尚未证明它能修复实际采图**。
需核对实际 PCB/连接器脚位，并实测该位对本模组时钟输出和接收的效果；
若实板已修正 P/N，则应关闭该选项。无需改变四条数据线的极性。

## 两种相机板不能混用的配置

| 项目 | 当前 SC132GS 板 | SC038HGS 板 |
| --- | --- | --- |
| 模组座 | 一个 22 针 | 两个 24 针，FPC1 / FPC2 |
| GPIO2 | 高有效 EN，控制 3.3 V 和 1.8 V LDO | FPC1 TRIG1 |
| GPIO3 | 图中未使用 | FPC2 TRIG2 |
| GPIO4 | 图中未使用 | 两个模组共用 PWDN |
| I2C | I2C1，GPIO34/35，经 TXS0102 转至 1.8 V | FPC1：I2C1；FPC2：I2C2，GPIO11/12 |
| MIPI | 单个逻辑 CSI0，D0–3 共用物理 CSI0/1 引脚组 | FPC1：CSI2/D4；FPC2：CSI0/D0，各一条数据线 |
| MCLK | 板载 Y1，图中未标频率 | 另一相机板的板载 Y1，不能据此推定新板频率 |

当前 `k230d_canmv_dart_v1_defconfig` 与其生成的配置应只启用 SC132GS/CSI0，
使用 I2C1、GPIO2 电源、无独立 reset、外部时钟、四条数据线及上述时钟反向设置。
独立 CSI1/CSI2 和 SC038HGS 均关闭。GPIO4 不参与这个版本的相机控制。
另一 RTOS defconfig 仍只支持 SC038HGS 板的 FPC1，不能称为双目完整支持；
同时启用两座前还需处理共用 PWDN，避免一座复位/关电干扰另一座。

## 尚未从图纸或实机确认的项目

- **Y1 频率**：图上只标 1.8 V 供电和 22 Ω 串阻，未写 MHz。
  `MPP_SC132GS_EXTCLK_HZ=24000000` 仍是假设值；不能用旧相机的时钟信息代替。
  改此数值只缩放驱动时序信息，不会自动生成匹配的 PLL 表。
- **四线输出**：`0x3018[7:5]=3` 有手册依据，但现有 PLL/模拟表来自仓库的两线模式。
  尚无该模组四线厂家验证表，不能保证仅设置 lane 数即可稳定采图。
- **装配情况**：EN 的 5 V 上拉 R1 标为 NC、R2 为 10 kΩ 下拉；
  I2C 的 R4–R7 标为 NC。图中电平转换存在，实际焊接与上拉仍需对应实板。
- **传感器类型及标定**：模组图不能证明黑白/彩色版本或 Bayer 顺序；
  仓库 ISP 文件也不代表已经针对这颗 120° 镜头重新标定。

代码修正、寄存器模拟、交叉编译和镜像校验只能验证软件与打包结果。
I2C ID、MIPI 时钟/数据、实际帧尺寸和连续到帧仍需板上验证。
